## How the exam works

- **100-mark papers:** 3 hours. Answer **any 5 of 7** questions, 20 marks each. Question 7 is always "short notes, any 3 of 5".
- **50-mark papers:** 1.5 hours. Answer **any 3** questions.
- Answers are written in English. Almost every question asks about **Nepal's position**, so learn the Nepal part of each unit, not only the theory.
- Most papers with prescribed cases have a full question on **one named case**: its facts, issue, decision and ratio decidendi.

## How to use these notes

1. Read the paper's overview first. It tells you which units are asked most often.
2. Read each unit top to bottom once. Underlined words show their meaning when you hover or tap them.
3. Try the **Test yourself** questions before opening the answers.
4. Practise the **model answers** by writing them out against the clock. See [How to write answers](how-to-answer.md).
5. Press **Mark this unit as read** at the bottom of a unit. A tick then shows in the menu. Ticks are saved in this browser only.
6. Before the exam, read only the **One-minute revision** box of each unit.

!!! warning "These are study notes, not legal advice"
    Law changes. Each unit names the sources and the version of each Act it was checked against. Anything not checked against a source is marked **Unverified**.
